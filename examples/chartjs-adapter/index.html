Chart.js / Canvas Adapter Pattern

Breeze preserves a zero-dependency, ultra-light runtime while enabling friction-free integration with rich vanilla JS ecosystems (Chart.js, D3, Leaflet, Three.js). By wrapping third-party libraries inside a lifecycle effect, external instances bind reactively to Breeze signals with automatic teardown.

The Canonical Adapter Pattern

// 1. Define your Breeze reactive signals
const dataset = Breeze.signal([24, 45, 68, 39, 82, 56], 'chartData');
const chartMode = Breeze.signal('bar', 'chartMode');

// 2. Wrap third-party library in an effect to automatically track updates
Breeze.effect(() => {
  const data = dataset.value;
  const mode = chartMode.value;

  // Seamlessly update your external Chart instance:
  chartInstance.update({ data, mode });
});
