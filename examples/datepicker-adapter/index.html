Vanilla DatePicker Two-Way Binding

This example demonstrates two-way reactive state synchronization between a vanilla JavaScript DOM component and Breeze reactive signals. Selecting a date in the calendar updates the Breeze signal, and modifying the Breeze signal programmatically syncs the calendar widget immediately.

September 2026
Bound Breeze Signal: 2026-09-11 Friday, September 11, 2026

Two-Way Synchronization Pattern

// 1. Declare the reactive Breeze signal
const selectedDate = Breeze.signal('2026-09-11', 'selectedDate');

// 2. Component -> Signal: Emit change event on user selection
calendarWidget.onSelect((isoDate) => {
  selectedDate.value = isoDate;
});

// 3. Signal -> Component: Reactively sync widget when signal changes
Breeze.effect(() => {
  calendarWidget.setDate(selectedDate.value);
});
